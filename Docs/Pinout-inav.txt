------------------------------------------------------------
SERIAL / UART
------------------------------------------------------------
USB VCP   PA11 (DM)     PA12 (DP)    — OTG FS
UART1     TX: PA9       RX: PA10     — TELEM1
UART2     TX: PA2       RX: PA3      — DJI O3 / TELEM2
UART3     TX: PD8       RX: PD9      — GPS
UART4     TX: PA0       RX: PA1      — spare
UART6     TX: PC6       RX: PC7      — RC INPUT (default SBUS)
UART7     TX: —         RX: PE7      — ESC telemetry
UART8     TX: PE1       RX: PE0      — companion computer
SBUS: no hardware inverter (PD0 not connected); the UART inverts RX in hardware

SERIAL_PORT_COUNT = 8 (VCP + 7 UARTs)

------------------------------------------------------------
SPI
------------------------------------------------------------
SPI1      SCK: PA5    MISO: PA6    MOSI: PA7
SPI2      SCK: PD3    MISO: PC2    MOSI: PC3

CS pins:
  BMI270        CS: PA15   (SPI2)
  BMI088 Accel  CS: PD4    (SPI2)
  BMI088 Gyro   CS: PD5    (SPI2)
  AT7456E OSD   CS: PD11   (SPI1)

IMU autodetect: BMI088 is probed first, BMI270 is used when no BMI088
is fitted. Alignment: BMI088 CW270_DEG, BMI270 CW0_DEG.

------------------------------------------------------------
I2C
------------------------------------------------------------
I2C1      SCL: PB6    SDA: PB7     — external connector
I2C2      SCL: PB10   SDA: PB11    — onboard baro + mag

Sensors on I2C2:
  Baro:  DPS368 (DPS310 driver)          addr 0x76
  Mag:   IST8310                          addr 0x0E   CW90_DEG
  Mag:   QMC5883L                         addr 0x0D   CW90_DEG

------------------------------------------------------------
MOTOR / PWM OUTPUT
------------------------------------------------------------
M1   PE14   TIM1_CH4   DSHOT
M2   PE13   TIM1_CH3   DSHOT
M3   PE11   TIM1_CH2   DSHOT
M4   PE9    TIM1_CH1   DSHOT
M5   PB1    TIM3_CH4   DSHOT
M6   PB0    TIM3_CH3   DSHOT
M7   PD12   TIM4_CH1   DSHOT
M8   PD13   TIM4_CH2   DSHOT
M9   PD14   TIM4_CH3   DSHOT
M10  PD15   TIM4_CH4   PWM only (H743 has no DMA request for TIM4_CH4)

USE_DSHOT_DMAR is NOT enabled (per-channel DMA DSHOT).
